# Blog Outline

## 标题

树莓派 + YOLOv8-Pose：如何设计一个智能老人陪伴与跌倒检测原型系统

## 1. 项目背景

独居老人可能面临跌倒、环境异常、忘记吃药等风险。这个项目尝试用低成本边缘设备实现一个轻量级安全监测系统。

## 2. 系统架构

系统分为四层：

- 感知层：DHT22、MQ-2、MQ-5、CSI Camera
- 算法层：环境阈值判断、跌倒风险评分
- 数据层：SQLite 本地记录
- 交互层：Gradio 多标签页界面

## 3. 为什么 GitHub 展示版使用模拟模式

硬件项目最大的问题是复现难。为了让面试官可以直接运行项目，公开仓库默认使用模拟数据，同时保留真实硬件扩展接口。

## 4. 跌倒风险检测设计

完整版本可以使用 YOLOv8n-Pose 提取关键点，演示版用模拟关键点复现风险评分逻辑。评分依据包括身体角度、肩髋相对位置和姿态突变。

## 5. 环境监测设计

温湿度、烟雾和可燃气体数据通过阈值判断生成告警。真实硬件可接入 DHT22、MQ-2、MQ-5 和 ADS1115。

## 6. 项目复盘

这个项目体现的核心能力不是单一模型调用，而是完整工程系统的搭建能力，包括模块拆分、异常降级、本地存储和界面展示。
